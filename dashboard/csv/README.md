# Таблицы для Yandex DataLens

Все файлы сохранены в UTF-8, используют запятую как разделитель и точку как десятичный разделитель. Значения рассчитаны по данным из `SQL/02_insert_data.sql` и определениям из `SQL/03_analytics_queries.sql`.

## Отдельные KPI

Каждая KPI-метрика вынесена в отдельный однострочный CSV. Файл можно сразу подключать к отдельному индикатору DataLens без фильтров.

| Файл | Показатель | Поле для индикатора |
|---|---|---|
| `total_listens.csv` | всего прослушиваний | `total_listens` |
| `active_listeners.csv` | активные пользователи | `active_listeners` |
| `retention_week_1.csv` | retention первой недели | `retention_week_1_pct` |
| `stickiness_january.csv` | липкость DAU/MAU за январь | `stickiness_pct` |
| `avg_top_artist_listens.csv` | среднее прослушиваний любимого исполнителя | `avg_top_artist_listens` |

Для `retention_week_1_pct` и `stickiness_pct` выберите числовой формат с суффиксом `%`. Значения уже находятся в шкале от 0 до 100, дополнительно умножать их на 100 не нужно.

## Таблицы для графиков

| Файл | Содержимое | Рекомендуемая визуализация |
|---|---|---|
| `dau_january.csv` | DAU по активным дням января | линейный график |
| `mau.csv` | MAU по месяцам | столбчатая диаграмма |
| `top_artists.csv` | топ-5 исполнителей | горизонтальная столбчатая диаграмма |
| `top_tracks.csv` | топ-10 треков | горизонтальная столбчатая диаграмма |
| `subscriptions.csv` | пользователи по подпискам | кольцевая диаграмма |
| `cohort_retention_long.csv` | retention в длинном формате | тепловая карта или линейный график |
| `cohort_retention_wide.csv` | retention в широком формате | таблица как на текущем дашборде |

## Настройка полей

- В `dau_january.csv` поле `activity_date` должно иметь тип «Дата», `dau` - «Целое число».
- В `mau.csv` поле `activity_month` должно иметь тип «Дата», `mau` - «Целое число».
- В рейтингах используйте название как измерение и числовой показатель как меру, затем включите сортировку по убыванию.
- В `cohort_retention_long.csv` используйте `cohort_start` по строкам, `period_number` по столбцам и `retention_pct` как цвет или значение.
- Поля с суффиксом `_pct` уже содержат проценты от 0 до 100.
