## Данные

Проект использует небольшой синтетический набор данных за период с 3 января по 11 марта 2024 года.

`tracks_amount` содержит справочное количество треков в полном альбоме, тогда как `tracks` включает только треки, используемые в учебной выборке.

В `listens` сохранены `track_id`, `artist_id` и `album_id`. Составной внешний ключ не позволяет записать событие, в котором треку указаны чужой исполнитель или альбом.

## Определения метрик

- **Активный пользователь**: пользователь хотя бы с одним прослушиванием в выбранном периоде.
- **DAU**: число уникальных активных пользователей за календарный день.
- **MAU**: число уникальных активных пользователей за календарный месяц.
- **Stickiness (DAU/MAU)**: средний DAU за все календарные дни месяца, включая дни без событий, деленный на MAU.
- **Retention первой недели**: доля пользователей когорты регистрации, совершивших хотя бы одно прослушивание на 7-13-й день после регистрации.
- **Недельный когортный retention**: доля пользователей когорты с активностью в каждом относительном семидневном периоде. Период 0 рассчитывается по фактической активности и не фиксируется на уровне 100%.

## Запуск

Требуется MySQL 8.0.16 или новее. `01_create_tables.sql` создает базу `musix_analytics`; следующие файлы явно выбирают ее через `USE`.

```bash
mysql -u <user> -p < SQL/01_create_tables.sql
mysql -u <user> -p < SQL/02_insert_data.sql
mysql -u <user> -p < SQL/03_analytics_queries.sql
```

Все запросы в `03_analytics_queries.sql` исполняемые и разделены комментариями. Их можно запускать вместе или по одному.
