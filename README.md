# Music Streaming Analytics Dashboard

SQL-проект и BI-дашборд для анализа вымышленного музыкального стримингового сервиса.

## Описание проекта

Проект представляет собой учебный аналитический кейс по музыкальному стриминговому сервису.

В рамках проекта была создана реляционная база данных, содержащая информацию о пользователях, исполнителях, альбомах, треках и прослушиваниях.  
На основе SQL-запросов были рассчитаны основные продуктовые и контентные метрики, после чего собран BI-дашборд в Yandex DataLens.

## Структура базы данных

В проекте созданы следующие таблицы:

- `users` — пользователи сервиса;
- `artists` — исполнители;
- `albums` — музыкальные альбомы;
- `tracks` — треки;
- `listens` — события прослушивания.

## Основные метрики

В проекте рассчитаны следующие метрики:

- общее количество прослушиваний;
- количество уникальных пользователей;
- MAU — Monthly Active Users;
- DAU — Daily Active Users;
- DAU/MAU — stickiness;
- Retention Rate;
- когортный анализ удержания;
- топ треков по прослушиваниям;
- топ артистов по уникальным слушателям;
- распределение пользователей по типу подписки;
- Artist Loyalty Index — среднее число прослушиваний любимого исполнителя среди пользователей.
